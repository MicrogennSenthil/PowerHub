PowerHub — MHMS Integration Specification

Room Power Automation · REST API v1
Rev 1.0 · July 2026

1. Overview

PowerHub exposes a single REST endpoint that your MHMS (Hotel Management System) calls to switch room power on or off. PowerHub then relays the command to the physical relay box in the room within a few seconds via the device's background polling cycle.

🔒 All MHMS-facing calls require an API Key issued per property from PowerHub → Integration → Power Automation. Keys are transmitted in a request header — never in the URL.

2. Authentication

Include the property API key in every request as an HTTP header:

X-API-Key: phk_58a4dc87f0f103596043c086b2640f9b5543f785

Keys are prefixed phk_ and are 44 characters total. Each key is scoped to one property. The key is displayed only once at creation — store it securely in MHMS configuration.

3. Command Endpoint

MethodURL
POSThttps://<powerhub-domain>/api/integration/power/commands

Content-Type: application/json

4. Request Body

FieldTypeRequiredDescription
roomNostringrequiredRoom number exactly as stored in PowerHub (e.g. "101")
statestringrequired"on" or "off"
processstringoptionalProcess name from PowerHub master: "Checkin", "Checkout", "Cleaning", "Visiting", etc. Drives auto-cutoff timer.
grcNostringoptionalGRC / folio reference number — appears in Power Usage report
billNostringoptionalBill / invoice number
guestNamestringoptionalGuest full name
usernamestringoptionalFront-office staff login who triggered the action
controlTypesstring[]optionalRestrict to specific load types, e.g. ["Light","A/C"]. Omit = all loads in room.

5. Example Requests

Check-in (power ON):

POST /api/integration/power/commands
X-API-Key: phk_58a4dc87f0f103596043c086b2640f9b5543f785
Content-Type: application/json

{
  "roomNo":    "101",
  "state":     "on",
  "process":   "Checkin",
  "grcNo":     "GRC-2026-001",
  "billNo":    "B10042",
  "guestName": "Mr Rahul Kumar",
  "username":  "receptionist1"
}

Check-out (power OFF):

POST /api/integration/power/commands
X-API-Key: phk_58a4dc87f0f103596043c086b2640f9b5543f785
Content-Type: application/json

{
  "roomNo":    "101",
  "state":     "off",
  "process":   "Checkout",
  "grcNo":     "GRC-2026-001",
  "username":  "receptionist1"
}

6. Response

202 Accepted — command queued successfully. The relay will switch within the device's next poll cycle (typically 2–5 seconds). 
{
  "queued":           2,          // number of relay channels switched
  "powerLogIds":      [41, 42],   // internal log IDs for tracing
  "room":             "101",
  "state":            "on",
  "process":          "Checkin",
  "autoCutoffMinutes": null,      // non-null if auto-cutoff applies
  "controls": [
    { "id": 3, "label": "A/C-1",  "type": "A/C" },
    { "id": 4, "label": "Light-1", "type": "Light" }
  ]
}

7. Error Codes

HTTP StatusMeaningAction
401Missing or invalid API keyCheck the X-API-Key header value
403Key disabledRe-activate or regenerate the key in PowerHub
404Room number not foundVerify room number matches PowerHub room master
400No controls mapped to room, or unknown processContact PowerHub administrator to map relay channels to the room
429Rate limit exceededBack off and retry after 10 seconds
500Server errorRetry once; if persistent contact PowerHub support

8. Standard Process Names

ProcessTypical UseAuto-Cutoff
CheckinGuest arrival — full power ONNo
CheckoutGuest departure — full power OFFNo
CleaningHousekeeping in roomYes (configurable, default 30 min)
VisitingShort guest visitYes (configurable, default 10 min)
ℹ️ Process names and cutoff durations are managed in PowerHub → Masters → Process Types. The MHMS team should confirm exact names with the hotel's PowerHub administrator.

9. Quick Integration Test (curl)

# Replace DOMAIN and KEY with actual values
curl -X POST https://DOMAIN/api/integration/power/commands \
  -H "X-API-Key: phk_YOUR_KEY_HERE" \
  -H "Content-Type: application/json" \
  -d '{"roomNo":"101","state":"on","process":"Checkin","guestName":"Test Guest"}'

Expected: HTTP 202 with a JSON body showing "queued": N. The room relay will switch within seconds.
